## Question

Design the Coach: a per-capability-Direction role — half log (Activity Log + quest/artifact evidence viewed per Direction, doubling as skill-claim performance evidence), half advice. Next steps = minted doing-quests; follow-ups = composed questions licensed by quest returns; reflection elicitation (what broke, what surprised) feeds the wiki. Advice constitution is LOCKED (Q-24): Marginalia-class, in-app only, choice-expanding (options never prescriptions), guilt-free (no streaks, no progress-shaming; dormancy is signal, never debt). Decide: the Coach surface, quest lifecycle, advice cadence, artifact-evidence linking.

## Resolution (2026-08-02)

Grilled with Micah, six questions, every recommended default confirmed.
Rulings minted as Q-73 through Q-78:

1. **Q-73** — coached is user-declared; the agent may only offer (Q-37
   shape, live per Q-62). Reversible; un-coaching archives nothing.
2. **Q-74** — a quest is offered as a set of 2-3 alternative acts; adoption
   mints; no deadlines or reminders; quest text is Marginalia-class.
3. **Q-75** — lifecycle offered → adopted → returned → retired; a return is
   ordinary capture tagged to the quest (harvested normally); no failure
   state, no expiry, no completion rate anywhere.
4. **Q-76** — one Coach page per coached Direction (log half + advice
   margin); quiet new-line on the waiting surface; no global Coach tab.
5. **Q-77** — advice event-licensed only; time licenses nothing; one unread
   note per Direction, replaced not stacked; declined options never
   re-offered.
6. **Q-78** — an artifact is a declared pointer plus the person's sentence;
   skill-claims cite the Snippets, never the file; the model never opens
   an artifact.

The design's unity: every Coach mechanism is either an offer (live under
Q-62) or the person's own act captured through the ordinary harvest path —
nothing acts, so nothing ships inert, and the Coach's entire evidentiary
output is the person's words with quest provenance.

Build is [090](090-build-coach.md) — a whole slice, /writing-plans with
reviewer rounds first, queued behind the ruled sequence.
