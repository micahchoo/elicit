| Q-17 | Resonance retrieval is a staged hybrid: lexical (phrase-echo, explainable, quotable) ships first; a local-embedding channel for disjoint-vocabulary clashes lands with the Clerk slice. The index stays derived and rebuildable. Embedding endpoint verified live: Ollama at `http://192.168.0.229:11434/v1/embeddings` — `qwen3-embedding` (4096-dim, provisional default; multilingual) and `nomic-embed-text` (768-dim, lighter). | Session decision (grill Q16); idiolect argument + Q-12 fit |
| Q-47 | A Sounding BECOMES the rest of the sitting: entering converts the remaining question budget into the descent's rung allowance (capped 8-12 per CONTEXT), and the two close moves (Q-20) are reserved BEYOND it, always. Rungs neither silently consume the close nor run unbounded — an uncapped consent-gated descent is how consent becomes an endurance test, however good the gates are. Because the total is knowable in advance, the user is told roughly how long the descent runs when asked to consent (Q-43), which is what makes the consent meaningful. A sitting that went deep is the one whose bookmark matters most, so the close is never sacrificed. | Session decision (Soundings grill Q5) |
| Q-46 | A Sounding ends structurally, never by model self-report: at the rung cap (8-12, mechanical), OR at convergence detected in CODE — the last two rungs produce answers that echo prior rungs (the same lexical machinery Resonance uses) or an answer is content-free by the pivot heuristic already in the elicitor. The agent is never asked "have we converged?" Same principle as Q-44 and adversarial-eval finding #6: no model self-report where a structural check will do. Ending is always announced as the descent closing, never as the user failing to go deeper. | Session decision (Soundings grill Q4) |
| Q-45 | A parked Sounding preserves THE LADDER: the ordered rungs (each question with the answer it drew), where the descent stopped, and which gate choice ended it — not a bare rung number (useless without the chain) and not a pre-composed next question (authored for a person who no longer exists by the time they return; compose fresh at resume, when what happened since is also visible). RESUMING IS COMPACTED, because the local model degrades on long payloads (adversarial eval finding #1): the prompt carries the last 1-2 rungs verbatim plus a one-line summary of the earlier ones, reusing the Cover consolidation mechanism (ADR-0002 layer 3). The full ladder stays on disk as truth (Q-3); the compaction is a prompt-time view. Ladder summaries are agent prose — Marginalia-class, never a Snippet, never shown at close (Q-20). | Session decision (Soundings grill Q3) |
| Q-44 | The mid-descent consent gate is ALWAYS PRESENT, never triggered: every rung carries the same three quiet margin words (continue / park, depth kept / another day), plus a mechanical checkpoint at the halfway rung. Discomfort is NEVER model-inferred — a model self-reporting a boolean is a suggestion, not a check (adversarial eval finding #6), and applying that to a person's emotional state is presumptuous as well as unreliable: an agent that says "I sense this is hard" on pattern-matched short sentences has told the user something false about themselves, the looping-effect harm the design guards everywhere else. An always-available gate is stronger than detection because stopping never requires being noticed; the counter-based checkpoint breaks answering-momentum without diagnosing anyone. Recorded signal is behavioral only — where you parked, how long you took, whether you chose another day. | Session decision (Soundings grill Q2) |
| Q-43 | A Sounding is agent-proposed and user-consented, never auto-entered. The PROPOSAL itself is licensed: late in the sitting, a Mode with energy for it, and a thread that has already sustained 3+ turns on one construct. Declining costs one word, is recorded as signal, and is never re-offered in the same sitting — a second ask converts an offer into pressure. Consent to ENTER is not consent to CONTINUE (the mid-descent gate is separate). Rationale: auto-entry is the interrogation Q-15 forbids; user-initiation alone would require the person mid-thought to self-diagnose that a thread has become load-bearing, which is the burden the tool exists to carry. | Session decision (Soundings grill Q1) |
| Q-42 | The composition slice ships in two passes, both in scope, in this order. Pass 1 is ZERO-LLM and complete on its own: manual initiation, one deterministic chronological Arrangement, reorder / remove / write-new-prose (Q-40) / insert-Gap (Q-39), export to markdown with pinned versions inlined, manual set-down (Q-41). Pass 2 adds the model: candidate Arrangements under distinct organizing principles (Q-38), skeleton Marginalia, stale-pin lint, auto-set-down. Agent OFFERS (Q-37) are excluded from both — they are licensed by citation-cluster density, which requires Claims, so they land with or after the Clerk slice. Rationale: arranging your own sentences is the product thesis and needs no model; a deterministic reviewer cannot hallucinate, cannot stall on a slow call, and makes pass 2 a pure addition rather than a correction. | Session decision (composition grill Q6) |
| Q-41 | A Piece is never "finished" — it is SET DOWN, reversibly. Setting down (by the user, or silently after long dormancy) stops Gap-question minting and lets existing gap questions expire on the normal queue rule; the Arrangement stays fully editable and picking it up resumes minting. No done flag, because "done" manufactures its complement — everything else becomes unfinished, which is the shame gradient Q-24 forbids (dormancy is signal, never debt). A set-down Piece stays first-class: its pins still count as citations, its Snippets still resonate, it still appears in re-reading. Auto-set-down is silent and logged (Q-23), never announced (Q-22). | Session decision (composition grill Q5) |
| Q-40 | Prose the user writes inside a Piece (transitions, connecting clauses, titles) becomes a Snippet — harvested like any other user prose, with composition provenance. One rule holds with no exceptions: all user prose in the system is a Snippet, and a Piece contains only Snippets. No second class of words that look like evidence but are uncitable and unversioned; the reviewer is another elicitation surface, and writing pulls corpus the same way it pulls questions. A title is body text, so a title is a Snippet too. | Session decision (composition grill Q4) |
| Q-39 | Gaps and stale pins are annotate-and-offer, never act. Gap detection is dual-authority (model marks empty slots while arranging; the user inserts them during review — same object, user-inserted gaps mint user-declared-weight questions). Each gap mints exactly one Gap-fill Queue question and clears only when the USER places a snippet; a fitting later harvest may be offered in the margin, never auto-placed. Stale pins (pinned snippet@vN where vN < latest) get a dimmed flag that NEVER auto-updates the pin — pinning a past self's words can be deliberate, and keeping an old pin against a newer version is itself diachronic signal; the choice is recorded either way. | Session decision (composition grill Q3) |
| Q-38 | Arrangement candidates: at most 3, usually 2, each under a DIFFERENT named organizing principle (chronology / argument / contrast) — never shuffles of one principle. Skeleton Marginalia names the principle and each snippet's role. Generated at acceptance time only — no warm speculative Arrangements in the Docket. Candidates contain snippet-version pins and Marginalia only: no agent transitions, no titles (a title is body text — Q-1). | Session decision (composition grill Q2) |
| Q-37 | Piece proposal licensing: user-initiated always; agent-side offers are PASSIVE — a dimmed lint-note-style line on the waiting surface, licensed by citation-cluster density (snippets interlinked through shared claims/contradictions, never topic-count alone — a pile is not a piece), threshold shadow-first (Q-35). Ignoring an offer is recorded signal, never escalated (Q-22). Writing pulls elicitation; the agent's only edge is knowing where the material got dense. | Session decision (composition grill Q1) |
| Q-36 | Question generation follows one standing principle: freedom in generation, rigidity in validation. The model receives ever more CONTEXT (transcript, resonance, and eventually the wiki, facet balance, exposure history, Mode) and ever fewer INSTRUCTIONS (repertoire, never prescription; quoting available, never mandatory for live probes — Q-12's verbatim rule binds composed questions only); every invariant is enforced by code guards at the boundary (parrot, degenerate, no-repeat, no conversation-reference, pivot-on-thin). Born from live-sitting evidence: prescriptive prompts produced quote-frame monoculture and echoes; see docs/question-composition.md. | Session decision (user diagnosis, ticket 031 + eval evidence) |
| Q-35 | Calibration is shadow-first graduation, per mechanism, no global calendar: every selection mechanism (facet-balance filter, exposure control, FSRS horizons, uptake signals — and any future one) runs in log-only shadow from day one, writing what it WOULD have decided to the Activity Log (Q-23, free evidence); each graduates to live individually when its shadow record over enough data earns it; every PROVISIONAL register entry names its graduation condition, not a date. Calibration is not a period the product passes through but the permanent rule for how mechanisms earn the right to act. | Session decision (Clerk grill Q8) |
| Q-34 | Model lifecycle: every agent-authored artifact (reading, claim, composed question, candidate judgment) carries a model stamp at creation. On upgrade, re-annotation is LAZY — the new model re-reads only what the Docket touches anyway; disagreement SUPERSEDEs the old reading with reason model-upgrade (Q-29 machinery, kept never deleted). Full re-annotation batch exists but only the user triggers it. Rationale: the wiki's history records drift in the person; a mass rewrite on upgrade day injects a discontinuity indistinguishable from self-change (Q-27) — lazy keeps model-drift diffuse, and stamps make it subtractable. | Session decision (Clerk grill Q7) |
| Q-33 | The wiki-editing surface is six verbs on a claim: Attest (→ user-attested), Refute (→ contested + Q-14 re-measure, or refute-with-prejudice → ARCHIVE with the user's reason — evidence, never deletion), Edit Range, Detach cite (status recomputes mechanically), Propagate (Q-4), Edit body — which flips the claim to user-attested automatically: the moment the words are the user's, the epistemic class changes. Agent prose and user prose never blur. | Session decision (Clerk grill Q6) |
| Q-32 | Identity registry write tiers: the model MINTs new referents freely (reversible), proposes-and-applies aliases (reversible; a wrong alias surfaces as an absurd Juxtaposition and is edited away), and NEVER merges canonical identities — merge candidates surface as dimmed notes on both registry entries (Q-31 mechanism) and only user attestation executes the merge. Principle: the model may add structure, link reversibly, never collapse; who counts as "the same" is self-description, not inference (Hacking). Registry entries are vault markdown (Q-3). | Session decision (Clerk grill Q5) |
| Q-31 | Staleness lint is graph computation, zero LLM calls, with one mechanical consequence per finding: stale citation (new snippet version flags citing Claims) → one still-true question minted per flagged Claim via the composeStillTrue path, tagged to clear on harvest; orphan claim (all cites superseded/archived) → dimmed lint note in the wiki, never auto-archived; god-node Facet → note only, no split op. Underlying rule: lint may ADD questions and annotations; it may never remove or restructure claims — the zero-LLM layer is incapable of damage by construction. | Session decision (Clerk grill Q4) |
| Q-30 | Synchronic contradiction pipeline: (1) candidates from both channels (lexical + embedding) into one Clerk-internal pool — two Claims on one construct (alias registry) with model-judged opposed Stances, both poles quoted; never user-facing. (2) Each candidate mints exactly ONE ask-differently re-measure question (Q-14, Q-12-composed) — the only gate. (3) A Contradiction opens only when the re-measured reading confirms opposition: both Claims → contested (mechanical), pair becomes Juxtaposition material — met as material, never accusation (Q-15). (4) Dissolved candidates are ARCHIVEd with outcome as reason — anti-repetition. Cap: ≤2 live re-measures in the Queue (PROVISIONAL until slice-2 RESULTS). | Session decision (Clerk grill Q3) |
| Q-29 | The Clerk's write contract: op vocabulary is MINT / UPDATE / MERGE / SUPERSEDE (reason required) / ARCHIVE / KEEP, and an op list must be total over the readings swept — KEEP makes "judged redundant" distinguishable from "silently omitted". Status is never model-writable; transitions are mechanical (≥2 independent cites → evidenced; Propagation → user-attested; open Contradiction → contested). Rejected ops are logged with reason and skipped; the reading stays unprocessed for the next run. The wiki-side mirror of Q-1: invariants checked at one code boundary, never per-prompt discipline. | Session decision (Clerk grill Q2) |
| Q-28 | Claim minting is immediate: every harvested reading mints or updates a Claim on the next docket run, born `unconfirmed` with a single cite. No convergence gate, no pending pool, no on-demand minting — Q-21's status enum and computed coreness carry the epistemic honesty; sprawl is pruned by MERGE ops and lint, not prevented by gating. | Session decision (Clerk grill Q1) |
| Q-27 | Re-reading's primary purpose is self-recognition — evidence of who you were, watched for drift; orientation and material-mining are side effects, never the frame. The wiki shows evidence; the user stays the authority (anti-looping). This is what the temporal spine (immutable versions, diachronic contradictions) exists to serve. | Session decision (fog grill Q24) |
| Q-26 | Phone sittings are second-class-but-supported now: LAN browser onto the server behind the password gate; a phone-width styling pass only (media query, touch-sized quiet actions). No native app, no sync, no offline — the vault never leaves the server. | Session decision (fog grill Q23) |
| Q-25 | Vault custody: the interface is password-locked (LAN access control); personal folders (vault/, data/ personal content) stay gitignored from the project repo permanently. Backup rides the user's existing file-backup infrastructure — the vault is plain files by design (Q-3). Flag, not fight: gitignored is not backed up; the vault path must be inside a backup regime. | Session decision (fog grill Q22, user redirect) |
| Q-24 | The Coach's advice constitution: advice is a new agent speech act — Marginalia-class (never in Pieces), in-app only (Q-22 intact), choice-expanding by rule (options, never prescriptions — von Foerster's imperative), and guilt-free by construction (no streaks, no progress-shaming; dormancy is signal, never debt). | Session decision (fog grill Q21) |
| Q-23 | Every deterministic and agentic act is logged to an append-only Activity Log rendered on the interface. Transparency is structural, not optional: background autonomy (Q-22) is only trustworthy because its ledger is inspectable. | Session decision; gist-mining anti-gaslighting finding |
| Q-22 | Zero outbound contact, ever — no notifications, no reminders, no content-triggered pushes. The Clerk works its Docket continuously in the background; finished work waits visibly on the interface until the user walks in. | Q-21 | Claim anatomy: body (one agent sentence) + mandatory Range (Bateson — no context-free trait claims) + mandatory cites + Status enum (unconfirmed/evidenced/user-attested/contested) + read-log (looping-effect flag). No confidence numbers; coreness computed from the citation graph, never stored. | Session decision (grill Q19); Bateson, STyLE-OLM, Hacking |
| Q-20 | Sessions close with two moves inside the budget: the open door ("anything else we didn't touch?") whose answer is volunteered, highest-signal material; then the bookmark ("where should we pick up?") whose answer stocks the Queue as a user-declared thread outranking agent-minted candidates. Agent session summaries are forbidden at close — reading the agent's frame before harvest review contaminates the evidence (looping effect). | Session decision (grill Q18); Kvale structuring, Hacking looping |
| Q-19 | Every sitting declares a Target (self or Domain) alongside Mode. Domain instruments — Critical Decision Method, laddered grid, concept sorting — are first-class Protocols, co-equal with self instruments. The product is workshop and mirror; without a declared Target the inward default wins by gravity. | Session decision (drift correction) |
| Q-18 | Random means shuffle, never invent: Randomizer draws come only from (1) the user's own forgotten snippets (depth-stratified resurfacing) or (2) user-curated decks. The agent may not generate "random" questions — its inventions are correlated with its own model and are the source of too-far noise. No distance metric exists or is needed. | Session decision (grill Q17); Ashby uncorrelated-source, Fu et al. "too far" |
