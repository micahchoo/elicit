What the draw actually does with the pool

src/queue/queue.ts draw(): filter chain (status → sounding → Mode needs → sharpness → horizon → target, with a relaxed second pass if the pool empties) → sort (user/gap-declared first, then newest) → facet balance (shadow by default) → top-3, picked uniformly at random (pickTopK) → mark asked.
